# canva-slide-excalidraw-style

Codex skill for creating simple 16:9 Canva-style presentation visuals with an Excalidraw-like hand-drawn look.

## Install with npx

After publishing this repository to npm:

```bash
npx canva-slide-excalidraw-style
```

To install directly from GitHub before publishing to npm:

```bash
npx github:OWNER/REPOSITORY
```

To choose a custom Codex skills directory:

```bash
npx canva-slide-excalidraw-style --path /path/to/.codex/skills
```

The installer places the skill at:

```text
<CODEX_HOME>/skills/canva-slide-excalidraw-style
```

If `CODEX_HOME` is not set, it uses `~/.codex/skills`.

## Use in Codex

Invoke it explicitly with:

```text
$canva-slide-excalidraw-style
```

## GitHub and npm

Create a GitHub repository from this folder, then publish the same package to npm when the package name is available. The GitHub command is useful for private or pre-release testing. The npm command is simpler for regular installation.
